# 率土之滨 · 同盟考勤查询（网页版）

打开页面 → 输入 **区服 / 同盟 / 个人 ID** → 查询同盟考勤数据。

- 在线地址：https://xiesy1234-coder.github.io/stzb-attendance/
- 形态：纯前端静态页（无后端依赖，可离线打开）
- 当前状态：**演示模式**——数据由输入确定性模拟生成，用于展示查询交互；接入数据源后替换为真实数据。

## 界面与交互

1. 输入 **区服（区号）**、**同盟（名称或 ID）**、**个人 ID（选填）**
2. 点击「查询」→ 展示：
   - 总览卡片（成员数 / 主力队伍 / 拆迁队伍 / 攻城次数 / 周武勋 / 达标率）
   - 成员考勤表（搜索、分组筛选、点表头排序、考核状态）
   - 分组周武勋（人数、合计、人均、达标人数与达标率）
3. 个人 ID 会**高亮定位**到对应成员（演示模式用 ID 数字映射）
4. 支持导出 CSV；支持分享链接直接带参数打开：

```
https://xiesy1234-coder.github.io/stzb-attendance/?server=1245&alliance=洛阳&playerId=12345
```

## 真实数据源（重要）

《率土之滨》没有公开的考勤查询接口；现有 GitHub 工具（如 stzb_watcher）都是**玩家电脑本地抓包 → 本地数据库 → 本地 API**（例如 `GET http://127.0.0.1:8080/api/attendance?union=xxx`）。

因此本页要出「真实数据」，需要下面任一方案：

| 方案 | 做法 | 说明 |
|---|---|---|
| A. 采集端上传 + 云端查询 | 玩家电脑跑采集端（抓包解析）→ 数据上传到你的后端 → 本页按 区服/同盟 查询 | 最接近理想体验，需要一台服务器 + 数据库 |
| B. 本地工具导出 → 网页导入 | 用现有工具导出 CSV/JSON，再在本页导入查询 | 无需服务器，但每次要手动导入 |
| C. 纯演示 | 保持当前模拟数据 | 只用于看界面/演示/给同盟成员解释需求 |

> 本页已把数据来源抽象为 `generateMock()`；接入真实 API 时，替换为 `fetch('/api/attendance?server=...&alliance=...')` 即可，界面无需改动。
