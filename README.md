# 率土之滨 · 同盟考勤（网页版）

一个纯前端（无后端、无依赖）的同盟考勤展示页，可直接在电脑浏览器或手机微信里打开。

- **定位**：只做数据呈现，不抓包、不上传任何数据。
- **数据来源**：导入 JSON / CSV，或使用内置示例数据。
- **存储**：浏览器 `localStorage`（本机保存，换设备不共享）。

## 目录结构

```
stzb-attendance/
├── index.html        # 页面结构
├── styles.css        # 样式（深色主题 + 移动端适配）
├── app.js            # 逻辑：导入/导出、筛选、排序、统计
├── sample-data.json  # 示例数据（可用于导入测试）
├── preview-desktop.png
└── preview-mobile.png
```

## 打开方式

1. **直接双击** `index.html` 即可（Chrome / Edge / 微信内置浏览器均可）。
2. 或在该目录启动一个静态服务（推荐，避免个别浏览器对本地文件的限制）：

```bash
cd stzb-attendance
# 任选其一
npx serve .
# 或：python -m http.server 8080
```

然后浏览器访问 `http://localhost:8080`。

## 功能

- **总览卡片**：成员数、主力队伍合计、拆迁队伍合计、攻城次数合计、周武勋合计、考核达标率
- **成员考勤表**：搜索、按分组筛选、点表头排序（成员/分组/主力/拆迁/攻城/周武勋/考核）
- **考核标准可调**：默认「主力 ≥ 2、拆迁 ≥ 1、攻城 ≥ 3」，可随时修改，表格与统计实时联动
- **分组周武勋**：各分组人数、武勋合计、人均武勋、达标人数与达标率，按武勋排序
- **数据导入**：支持 JSON / CSV / 拖拽文件
- **数据导出**：导出 JSON（备份/再导入）或 CSV（Excel 打开）
- **移动端适配**：表格横向滚动，卡片自动换行

## 导入数据格式

### JSON

```json
{
  "alliance": "我的同盟",
  "season": "S1 第 3 周",
  "members": [
    { "name": "张三", "group": "一组", "mainTeams": 3, "siegeTeams": 2, "attackCount": 12, "weeklyMerit": 15200 }
  ]
}
```

也可以直接给数组：`[{ "name": "...", ... }]`。

### CSV

首行为表头，支持中英文列名：

```csv
成员,分组,主力队伍,拆迁队伍,攻城次数,周武勋
张三,一组,3,2,12,15200
```

（英文列名 `name,group,mainTeams,siegeTeams,attackCount,weeklyMerit` 同样支持。）

## 部署上线

纯静态文件，任选一种：

- **GitHub Pages**：推送到仓库 → Settings → Pages → 选分支即可获得 HTTPS 地址；
- **Netlify / Vercel**：拖拽文件夹即可部署；
- **任意静态服务器 / 对象存储**（需 HTTPS，便于微信内打开）。

> 微信里直接打开 HTTPS 网页即可，无需小程序审核；后续如要做小程序，可复用同一套数据结构和后端接口。
